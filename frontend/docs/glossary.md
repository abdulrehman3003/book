# Glossary

A comprehensive reference of terms used throughout this book.

## A

**Actuator**
: A mechanical device that converts energy into motion. In robotics, actuators move joints and limbs.

**Action (ROS 2)**
: A communication pattern for long-running tasks that provides goal, feedback, and result messages.

**ADAS (Advanced Driver Assistance Systems)**
: Technologies that assist drivers, often using similar sensors and algorithms as robots.

**AGV (Automated Guided Vehicle)**
: A mobile robot that follows markers or wires for navigation in warehouses.

**AI (Artificial Intelligence)**
: Computer systems that can perform tasks requiring human-like intelligence.

## B

**Backlash**
: Play or slack in mechanical systems, particularly in gears, causing positioning errors.

**Bandwidth**
: The data transfer rate of a communication channel, measured in bits per second.

**Bipedal**
: Having two legs, like humans. Bipedal robots walk on two legs.

**BLDC (Brushless DC Motor)**
: An electric motor without brushes, offering higher efficiency and longer lifespan.

**BOM (Bill of Materials)**
: A list of all components needed to build a robot.

## C

**Calibration**
: The process of adjusting sensors and actuators to ensure accurate measurements and movements.

**CAN Bus (Controller Area Network)**
: A robust communication protocol commonly used in automotive and robotics.

**Cartesian Space**
: 3D space defined by X, Y, Z coordinates, as opposed to joint space.

**CoM (Center of Mass)**
: The point where an object's mass is concentrated, critical for balance.

**Compliance**
: The ability of a robot to yield to external forces, important for safety.

**Control Loop**
: A feedback system that continuously adjusts outputs based on sensor inputs.

**CPU (Central Processing Unit)**
: The main processor in a computer that executes instructions.

## D

**DDS (Data Distribution Service)**
: The middleware used by ROS 2 for inter-process communication.

**Deadband**
: A range of input values that produce no output, used to prevent oscillation.

**Degrees of Freedom (DOF)**
: The number of independent movements a robot can make. A humanoid typically has 20-40 DOF.

**DH Parameters (Denavit-Hartenberg)**
: A convention for describing robot kinematics using four parameters per joint.

**Digital Twin**
: A virtual replica of a physical system used for simulation and testing.

**Domain Randomization**
: Varying simulation parameters to create robust policies that transfer to real hardware.

## E

**Embodied AI**
: Artificial intelligence that interacts with the physical world through sensors and actuators.

**Encoder**
: A sensor that measures position or rotation, typically attached to motors.

**End Effector**
: The device at the end of a robotic arm (gripper, tool, etc.).

**ESC (Electronic Speed Controller)**
: A device that controls the speed of brushless motors.

**E-Stop (Emergency Stop)**
: A safety mechanism that immediately halts all robot motion.

## F

**Feedback**
: Information about a system's output used to adjust its behavior.

**Force/Torque Sensor**
: A device that measures forces and torques applied to it.

**Forward Kinematics**
: Calculating end-effector position from joint angles.

**FPS (Frames Per Second)**
: The rate at which images are captured or processed.

**Friction**
: Resistance to motion between surfaces, affecting robot movement.

## G

**Gait**
: The pattern of leg movements during walking or running.

**Gazebo**
: An open-source 3D robot simulator.

**Gear Ratio**
: The ratio between input and output speeds in a gear system.

**GPU (Graphics Processing Unit)**
: A processor optimized for parallel computations, used for AI and rendering.

**Grasp**
: The act of holding an object with a gripper or hand.

## H

**H-Bridge**
: An electronic circuit that allows bidirectional motor control.

**Haptic**
: Relating to the sense of touch, used in force feedback systems.

**Heartbeat**
: A periodic signal indicating a system is alive and functioning.

**Humanoid**
: A robot with a human-like form, typically with head, torso, arms, and legs.

**Hydraulic**
: Using pressurized fluid to generate force and motion.

## I

**I2C (Inter-Integrated Circuit)**
: A communication protocol for connecting sensors and peripherals.

**IMU (Inertial Measurement Unit)**
: A sensor combining accelerometer, gyroscope, and sometimes magnetometer.

**Impedance Control**
: A control strategy that regulates the relationship between force and motion.

**Inference**
: Running a trained AI model to make predictions.

**Inverse Kinematics (IK)**
: Calculating joint angles needed to reach a desired end-effector position.

## J

**Jacobian**
: A matrix relating joint velocities to end-effector velocities.

**Jetson**
: NVIDIA's embedded computing platform for AI and robotics.

**Joint**
: A connection between robot links that allows relative motion.

**Joint Space**
: The space defined by joint angles, as opposed to Cartesian space.

## K

**Kalman Filter**
: An algorithm for estimating system state from noisy measurements.

**Kinematics**
: The study of motion without considering forces.

**Kinect**
: Microsoft's depth camera, popular in robotics research.

## L

**Latency**
: The delay between input and output in a system.

**LIDAR (Light Detection and Ranging)**
: A sensor that uses laser pulses to measure distances and create 3D maps.

**Link**
: A rigid body in a robot's kinematic chain.

**LLM (Large Language Model)**
: An AI model trained on text data, like GPT-4.

**Locomotion**
: The ability to move from place to place.

## M

**Manipulation**
: The act of moving and controlling objects with a robot.

**MoveIt**
: A motion planning framework for ROS.

**Multi-Modal**
: Using multiple types of input (vision, language, touch, etc.).

## N

**Nav2 (Navigation2)**
: ROS 2's navigation stack for autonomous mobile robots.

**Node (ROS 2)**
: An independent process that performs a specific task.

**NVIDIA Isaac**
: A platform for robot simulation and AI development.

## O

**Odometry**
: Estimating position by integrating motion measurements.

**Omniverse**
: NVIDIA's platform for 3D simulation and collaboration.

**Open-Loop Control**
: Control without feedback, less accurate than closed-loop.

**Overfitting**
: When an AI model performs well on training data but poorly on new data.

## P

**PID (Proportional-Integral-Derivative)**
: A common control algorithm that adjusts output based on error.

**Pitch**
: Rotation around the lateral (side-to-side) axis.

**Pneumatic**
: Using compressed air to generate force and motion.

**Point Cloud**
: A set of 3D points representing a surface or object.

**Pose**
: Position and orientation combined (6 DOF: x, y, z, roll, pitch, yaw).

**PWM (Pulse Width Modulation)**
: A technique for controlling motor speed by varying pulse duration.

## Q

**QoS (Quality of Service)**
: Settings that control message delivery reliability and latency in ROS 2.

**Quadruped**
: A robot with four legs, like Boston Dynamics' Spot.

**Quaternion**
: A mathematical representation of 3D rotation using four numbers.

## R

**RANSAC (Random Sample Consensus)**
: An algorithm for fitting models to data with outliers.

**Real-Time**
: Systems that must respond within strict time constraints.

**Reinforcement Learning (RL)**
: Training AI through trial and error with rewards.

**RGBD**
: RGB color image plus depth information.

**Roll**
: Rotation around the longitudinal (front-to-back) axis.

**ROS (Robot Operating System)**
: A middleware framework for robot software development.

**RTX**
: NVIDIA's ray-tracing technology for realistic rendering.

**RViz**
: ROS's 3D visualization tool.

## S

**SLAM (Simultaneous Localization and Mapping)**
: Building a map while determining the robot's location within it.

**SDF (Simulation Description Format)**
: Gazebo's format for describing robot models and worlds.

**Sensor Fusion**
: Combining data from multiple sensors for better estimates.

**Servo Motor**
: A motor with built-in position feedback and control.

**Sim-to-Real**
: Transferring policies trained in simulation to real hardware.

**SLERP (Spherical Linear Interpolation)**
: Smooth interpolation between orientations.

**SPI (Serial Peripheral Interface)**
: A high-speed communication protocol for sensors and peripherals.

## T

**TF (Transform)**
: ROS's system for tracking coordinate frames.

**Torque**
: Rotational force, measured in Newton-meters (Nm).

**Trajectory**
: A path through space over time, including position, velocity, and acceleration.

**UART (Universal Asynchronous Receiver-Transmitter)**
: A serial communication protocol.

**URDF (Unified Robot Description Format)**
: An XML format for describing robot models in ROS.

## V

**VLA (Vision-Language-Action)**
: AI models that combine visual perception, language understanding, and action generation.

**VSLAM (Visual SLAM)**
: SLAM using camera images instead of LIDAR.

## W

**Waypoint**
: A point along a planned path.

**Whisper**
: OpenAI's speech recognition model.

**Workspace**
: The volume of space a robot can reach.

## Y

**Yaw**
: Rotation around the vertical axis.

**YOLO (You Only Look Once)**
: A fast object detection algorithm.

## Z

**Zero Moment Point (ZMP)**
: A point on the ground where the sum of all forces equals zero, used for balance control.
